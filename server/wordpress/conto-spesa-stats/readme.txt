=== Conto Spesa – Statistiche ===
Riceve le statistiche d'acquisto pseudonime dell'app Conto Spesa (solo con consenso),
mostra la dashboard in Bacheca → Conto Spesa e genera report aggregati (min. 10 utenti) per i partner.

Installazione: Plugin → Aggiungi nuovo → Carica plugin → scegli conto-spesa-stats.zip → Installa → Attiva.
Poi: Bacheca → Conto Spesa → compila Titolare ed Email privacy → crea una pagina con [contospesa_informativa].
